Provisions sidebar pace-layer sections from a registry JSON.

## What you get

- Preview by default, with explicit apply mode to create missing sections.
- Ownership by section ID, preserving renamed section labels.
- Explicit adoption of empty sections and reenabling of deleted layers.
- CLI status, provision, adopt, enable-layer and export commands.
- A provision run every 15 minutes and an RPC listing active owned sections.

Enable Layer groups under Installed plugins, then configure `registryPath`.
Inspect `bb layer-groups provision` in preview before selecting apply.
