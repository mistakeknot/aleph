# Journeys and roadmap

Aleph's goal is to spend usage on project progress instead of orchestration
overhead. The vision, personas, backlog and roadmap are in `docs/aleph-*.md`.

There are <!--fig:journeys=8-->8 critical user journeys in `docs/cujs/`:
multi-day coordinator, structured child results, cheapest adequate model, no
dead jobs, coordinator rotation, usage per outcome, upstream update, and
remote access across an upgrade.

The roadmap orders work as: measure the waste, remove wake storms and dead
jobs, bound review and returns, then rotation and routing, with fork
maintenance alongside.
